3D 공간과 시간 속에서 움직이는 코딩 에이전트 — Claude Code 세션을 실시간으로 보고, 지난 세션을 다시 재생하는 뷰어입니다.

★ GitHub에서 보기 최신 릴리스

Claude Code에 이렇게 말하세요

https://github.com/burn001/agent4d 에서 Agent4D 를 설치해 줘. ~/agent4d 에 클론하고, skills/agent4d 폴더를 ~/.claude/skills/agent4d 로 연결(Windows 는 정션)한 뒤, 실행해서 링크를 알려 줘.

  • 메인 에이전트와 서브에이전트, 워크플로, claude -p 세션, 백그라운드 명령까지 이 PC의 대화 기록(transcript)을 읽어 실시간으로 보여 줍니다(읽기 전용).
  • 흐름(Flow)·Planet·복셀 오피스(Voxel Office) 세 가지 화면을 3D로, 또는 가벼운 2D로 볼 수 있습니다.
  • 지난 세션을 다시 보고, 컨텍스트 사용률과 요금제 사용 한도를 확인하고, 이 PC의 모든 프로젝트를 한 화면에서 함께 지켜볼 수 있습니다.

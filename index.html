Visual Companion for Lonely Vibecoders

Your coding agents in 3D space + time — a live viewer and replayer for Claude Code sessions.

Tell Claude Code

Install Agent4D from https://github.com/burn001/agent4d — clone it to ~/agent4d, link its skills/agent4d folder into ~/.claude/skills/agent4d (a junction on Windows), then start it and give me the link.

  • Main agent, subagents, workflows, claude -p sessions and background commands, streamed live from local transcripts (read-only).
  • Three views — Flow, Planet and Voxel Office — in 3D or lightweight 2D.
  • Replay past sessions, see context usage and plan limits, and follow every project on your machine at once.
